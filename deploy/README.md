# Установка на Ubuntu / FirstVDS

Целевой домен: **waifudownload.hopto.org**. Адрес: **212.57.115.62**.
Новый контейнер публикуется только на **127.0.0.1:8787**, внешний доступ — через существующий Nginx и HTTPS.

## 1. Получить исходники

После публикации кода на GitHub можно обойтись без WinSCP. В PuTTY выполни этот блок целиком; он остановится, если каталог версии уже существует:

```bash
(
set -eu
cd /opt
test ! -e /opt/waifu-sync-2.1.0
curl -fL https://github.com/MakarBogatyrev1/waifu-downloader/archive/refs/heads/main.tar.gz -o /opt/waifu-sync-source.tar.gz
mkdir /opt/waifu-sync-2.1.0
tar -xzf /opt/waifu-sync-source.tar.gz --strip-components=1 -C /opt/waifu-sync-2.1.0
cd /opt/waifu-sync-2.1.0
docker compose version
ss -lnt '( sport = :8787 )'
)
```

Ветка main может изменяться; для воспроизводимой установки используй архив конкретного коммита или приложенный архив версии.

### Вариант с готовым серверным архивом

Через WinSCP (SFTP, тот же сервер и root, что в PuTTY) загрузи `waifu-sync-server-2.1.0.tar.gz` в `/opt/`.
Пароль вводится только в WinSCP/PuTTY. Он не нужен приложению и не входит в архив.

В PuTTY:

```bash
(
set -eu
cd /opt
test ! -e /opt/waifu-sync-2.1.0
mkdir /opt/waifu-sync-2.1.0
tar -xzf /opt/waifu-sync-server-2.1.0.tar.gz -C /opt/waifu-sync-2.1.0
cd /opt/waifu-sync-2.1.0
docker compose version
ss -lnt '( sport = :8787 )'
)
```

Если последняя команда показывает слушающий процесс, **не запускай контейнер**: порт уже занят. При предыдущей проверке он был свободен.
Если Docker Compose недоступен, сначала установи плагин Compose для своей установки Docker.

## 2. Собрать и запустить

```bash
cd /opt/waifu-sync-2.1.0
docker compose -p waifu-sync config --quiet
docker compose -p waifu-sync up -d --build
curl --fail http://127.0.0.1:8787/health
```

Первый запуск собирает Rust-сервер. Нужен доступ к Docker Hub и crates.io; на малом VDS сборка может занять несколько минут. При нехватке памяти контейнеры других проектов не останавливай: сборку можно выполнить на другой Linux-машине и перенести образ.

## 3. Подключить отдельный сайт Nginx

```bash
bash deploy/install-proxy.sh
```

Скрипт проверяет текущий Nginx и ответ сервера. Не перезаписывает существующий файл или домен. Новый конфиг проверяется до reload; при ошибке проверки скрипт удаляет только созданные им файлы. Старые сайты не редактируются. Если после проверки reload не удался, проверь `systemctl status nginx` и не перезапускай Nginx вслепую.

## 4. Выпустить HTTPS-сертификат

Проверь, что A-запись домена указывает на сервер и порт 80 доступен извне. Если есть AAAA-запись, она тоже должна вести на этот сервер.

Если Certbot уже установлен, переиспользуй его. Если нет:

```bash
apt-get update
apt-get install -y certbot python3-certbot-nginx
```

Затем:

```bash
certbot --nginx -d waifudownload.hopto.org --redirect
nginx -t
curl --fail https://waifudownload.hopto.org/health
certbot renew --dry-run
```

Адрес почты, который может спросить Certbot, относится к сертификату сервера; пользователям приложения почта не нужна. Проверь, что автоматическое продление сертификатов включено для установленного Certbot. Если используется другой клиент сертификатов, настрой сертификат через него вместо установки второго.

**До успешной HTTPS-проверки не создавай реальные аккаунты через HTTP.** В приложении адрес по умолчанию уже указан: `https://waifudownload.hopto.org`.

## Проверка после установки

1. Запусти новую Windows-версию, открой «Войти в аккаунт» → «Создать аккаунт».
2. Добавь картинку в избранное, создай альбом и добавь её туда.
3. Войди тем же логином на другом устройстве и нажми «Синхронизировать».
4. Измени тему: она должна появиться на другом устройстве в течение примерно 30 секунд.

Если сервер недоступен, просмотр и локальное сохранение продолжают работать. Облачные действия подтверждаются сервером; очередь изменений для работы без сети не реализована. Не закрывай приложение, пока оформление ожидает отправки. Одновременное изменение оформления — последнее полученное сервером значение. Остальные действия меняют отдельные элементы и не заменяют всю коллекцию другой копией.

## Данные и резервные копии

SQLite хранится в Docker volume `waifu-sync_sync-data`. Не удаляй его и не запускай `docker compose down -v`. Обычный `docker compose down` сохраняет данные. Проект ограничен 10000 аккаунтами, 10000 избранных картинок и 100 альбомами на аккаунт; суммарно до 8 МБ метаданных коллекции. Картинки на сервер не загружаются.

Согласованная резервная копия всей папки данных, включая журнал SQLite (с краткой остановкой только нового сервиса):

```bash
cd /opt/waifu-sync-2.1.0
mkdir -p /opt/waifu-sync-backups
chmod 700 /opt/waifu-sync-backups
docker compose -p waifu-sync stop sync
backup="/opt/waifu-sync-backups/sync-$(date +%Y%m%d-%H%M%S)"
if docker compose -p waifu-sync cp sync:/data "$backup"; then
    chmod -R go-rwx "$backup"
fi
docker compose -p waifu-sync start sync
```

Копии содержат приватные коллекции и хеши паролей: храни их с ограниченным доступом и копируй на отдельный носитель. Для автоматизации резервного копирования настрой свою систему бэкапов. Процедуру восстановления сначала проверяй на отдельном тестовом экземпляре.

Почта и автоматическое восстановление пароля отсутствуют. Администратор может сбросить пароль с помощью `server/reset-password.py` при остановленном контейнере; процедура ниже. Сессии действуют 30 дней, выход отзывает текущую сессию. Смена пароля через административный скрипт отзывает все сессии аккаунта.

## Сброс забытого пароля

На VDS нужен Python 3 с пакетом argon2 (Ubuntu: `apt-get install python3-argon2`). Скрипт спрашивает новый пароль через скрытый ввод; пароль не указывается в командной строке.

```bash
cd /opt/waifu-sync-2.1.0
docker compose -p waifu-sync stop sync
data_dir=$(docker volume inspect waifu-sync_sync-data --format '{{.Mountpoint}}')
python3 server/reset-password.py "$data_dir/waifu-sync.sqlite3" нужный_логин
docker compose -p waifu-sync start sync
```

## Отключить новый сервис

```bash
cd /opt/waifu-sync-2.1.0
docker compose -p waifu-sync down
```

Это не затрагивает остальные Docker-проекты. Конфиг Nginx и сертификат остаются; при полном удалении убери только сайт `waifu-sync.conf`, затем проверь `nginx -t` и выполни reload. Volume удаляется только осознанно после бэкапа.
