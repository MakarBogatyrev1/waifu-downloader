# Waifu Downloader

Галерея на Python / CustomTkinter с загрузкой из Waifu.im v7.

## Запуск

Требуется Python 3.10+ с Tkinter (в установщике Python для Windows включён по умолчанию).

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe waifu.py
```

Запускайте из папки проекта: настройки сохраняются в settings.json, картинки — в images/ либо выбранную папку.

## Использование

- Выберите SFW или NSFW и тег, затем нажмите «Следующая».
- Теги загружаются из API при запуске; список общий для обоих режимов.
  Если у тега нет изображений в выбранном режиме, приложение сообщит об этом.
- Загрузка выполняется в фоне. Повторный запрос блокируется до завершения;
  результат игнорируется, если за это время изменились параметры.
- Миниатюры открывают полное изображение. «Сохранить» записывает PNG в полном
  разрешении; предпросмотр уменьшается только для экрана.
- Режимы сохранения: A — images/<режим>/<тег>, B — images/, C — выбранная папка.
- Пользовательский URL — адрес JSON API, возвращающего items[0].url или url.
  В этом режиме фильтры SFW/NSFW и тег задаются самим URL.
- Для анимированных файлов используется первый кадр.

Основной API: GET /images, IncludedTags, IsNsfw, PageSize=1, Accept-Version: v7.
Ключ API для этих запросов не нужен. При HTTP 429 выполняются до трёх повторов
с учётом Retry-After; остальные ошибки отображаются в строке состояния.

Старые настройки папок и интерфейса сохраняются. Старая категория остаётся,
если совпадает с доступным тегом; иначе выбирается waifu. Если список тегов
недоступен, временно доступен waifu. Старые файлы не перемещаются.

## Проверки

```powershell
python -m unittest discover -s tests -v
```

Тесты не обращаются к сети. Часть проверок создаёт скрытое окно Tkinter и
требует окружения с графическим дисплеем.
