# Проверка Waifu Gallery 2.2

- 20 локальных Rust-тестов пройдены (2 внешних сценария пропущены).
- Проверено сохранение исходной ссылки рядом с PNG, чтение после открытия с диска, запись метаданных до завершения фонового сохранения и сохранение локального избранного в настройках.
- Проверены сравнение версий, отклонение чужих адресов загрузки, SHA-256 и тип Windows x64 EXE.
- PowerShell: синтаксис трёх скриптов проверен. Настоящая замена файла в тестовой папке, резервная копия и отказ при неверной контрольной сумме проверены запуском.
- Полная установка в пользовательские папки Windows/«Пуск» в ограниченной среде не выполнялась; требуется проверка установщика в обычной пользовательской сессии.
- Применение настоящего будущего GitHub Release пока не проверено: нужен опубликованный релиз с более высокой версией и asset WaifuGallery.exe. Транспорт использует HTTPS, адреса GitHub и digest из GitHub REST API.
- Сервер аккаунтов не менялся, обновлять VDS не требуется.

- Готовый EXE: локальный HTTP-сервер, реальный PNG 800×1131, сохранение .waifu.json, повторное открытие с исходной ссылкой, коллекция и снимки интерфейса — пройдены. Внешний Waifu.im недоступен из среды этого запуска; сетевой код API не изменялся.
