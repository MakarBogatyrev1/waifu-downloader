# Проверка Waifu Gallery 2.1

- Rust-клиент: 17 локальных тестов пройдены.
- Rust-сервер: 3 локальных теста пройдены, включая суммарный лимит метаданных аккаунта.
- HTTP-проверка настоящего сервера: регистрация, вход, разделение аккаунтов, идемпотентное избранное, альбомы, оформление между сессиями, параллельные изменения, ограничения тела запроса, Argon2id, хеши токенов, отзыв сессии, перезапуск и ограничение попыток входа — пройдены.
- Rust-клиент с настоящим сервером: регистрация, избранное, оформление и выход — пройдены.
- Windows Credential Manager недоступен в среде проверки: проверен запасной режим сессии до закрытия приложения. Сохранение и восстановление сессии через Windows API требует проверки в обычной пользовательской Windows-сессии.
- Docker Compose: конфигурация проверена командой config --quiet.
- Docker Engine в среде не ответил; Linux-образ и конфигурация Nginx на VDS ещё не проверены запуском. Установка включает nginx -t, /health и проверку HTTPS.
- Удалённое размещение и сертификат пока не выполнены.

- Native EXE: реальная загрузка Waifu.im v7, PNG 2250×4000, открытие из коллекции, светлая/тёмная темы, вкладки настроек и окно входа — пройдены; снимки проверены визуально.
