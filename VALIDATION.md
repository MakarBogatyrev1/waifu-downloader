# Проверка 2.4.0

24 теста прошли, 2 сетевых теста пропущены. Локальный HTTP-тест проверяет получение категорий, шаблон с пробелом, вложенный JSON и загрузку изображения без Waifu.im-заголовков. Тест дискового worker проверяет повторное сохранение после восстановления индекса — остаётся один PNG.
Native Windows smoke проверяет сохранённый статус и избранное по исходной ссылке, листание коллекции без изменения истории, исходное разрешение и делает снимки интерфейса. Внешние API и работа реального облачного аккаунта в этом обновлении не проверялись.
